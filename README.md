# D435 Scanner

Intel RealSense **D435** 깊이 카메라로 물체나 사람을 3D 스캔하고, 다듬고, 3D 프린팅용 **STL**로 저장하는 Windows 프로그램입니다.

- **물체 스캔:** 카메라를 손에 들고 물체 주위를 돌며 촬영합니다.
- **사람 스캔:** 카메라를 고정하고 회전의자에 앉아 한 바퀴 돕니다. 배경은 자동으로 제거됩니다.
- **정밀 재구성:** 스캔이 끝나면 녹화한 프레임으로 처음부터 다시 계산해 깨끗한 메시를 만듭니다.
- **편집기:** 박스로 원하는 부분만 잘라 바닥이 평평한 STL(mm)로 저장합니다.
- **다듬기 도구:** 조각 잇기, 구멍 메우기, 끌어서 모양 다듬기, 가우시안 스무딩을 할 수 있습니다.

## 1. 설치

### 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10 / 11 (64비트) |
| 카메라 | Intel RealSense D435 (D400 계열이면 대부분 동작) |
| 연결 | **USB 3 포트(보통 파란색) + USB 3 케이블** 권장. USB 2에서도 동작하지만 15fps로 낮아져 추적이 불안정합니다 |
| 메모리 | 8GB 이상 (16GB 권장, 정밀 재구성에 메모리를 많이 씁니다) |
| 그래픽 | OpenGL 3.3 이상을 지원하는 그래픽 카드 (대부분의 내장·외장 그래픽) |
| 디스크 | 프로그램 약 550MB + 스캔 하나에 수백 MB |

### 설치 순서

1. `D435_Scanner_Setup_1.2.0.exe`를 실행합니다.
2. **설치 폴더**를 고릅니다. 관리자 권한 없이 사용자 폴더에 설치되며, 원하는 곳(예: `D:\D435 Scanner`)으로 바꿀 수 있습니다.
3. **스캔 저장 폴더**를 고릅니다. 스캔 하나에 수백 MB가 쓰이므로 여유 공간이 많은 드라이브를 고르세요. 나중에 프로그램에서 바꿀 수 있습니다.
4. 설치가 끝나면 바탕 화면이나 시작 메뉴의 **D435 Scanner**를 실행합니다.

- **별도 드라이버는 필요 없습니다.** D435는 Windows 기본 USB 카메라 드라이버로 동작하고, RealSense 라이브러리와 VC++ 런타임은 프로그램에 들어 있습니다.
- **제거:** 시작 메뉴의 "D435 Scanner 제거" 또는 Windows 설정 > 앱에서 제거합니다. **스캔 저장 폴더는 지우지 않습니다.**

## 2. 처음 실행하기

D435 Scanner를 실행하면 아래 실행 화면이 뜹니다. 모든 기능을 여기서 버튼으로 실행합니다.

| 영역 | 내용 |
|---|---|
| **카메라** | 연결된 카메라 이름, 펌웨어, USB 종류를 보여줍니다. 카메라를 나중에 꽂았다면 [카메라 다시 확인] |
| **1. 스캔** | [물체 스캔] / [사람 스캔 (회전의자)]와 스캔 설정 |
| **2. 열기 · 편집** | [스캔 열기 (편집기)] / [다듬기 도구] |
| **3. 합치기 · 다시 보정** | 두 스캔 잇기, 예전 스캔을 최신 방식으로 다시 계산 |
| **저장 폴더** | 스캔이 저장되는 폴더. [폴더 바꾸기] / [폴더 열기] |
| **진행 상황** | 실행 중인 작업과 진행 로그. [작업 중지] / [로그 폴더 열기] |

- 각 작업은 **별도 창**으로 열립니다. 작업 창을 닫아도 실행 화면은 그대로 있습니다.
- 작업 창이 갑자기 꺼지면 진행 상황에 "비정상 종료"와 오류 코드가 표시되고, 자세한 내용은 로그 폴더에 남습니다.

### 스캔 설정

| 설정 | 설명 |
|---|---|
| 정밀 재구성 해상도 (mm) | 기본 2mm. 작을수록 세밀하지만 느리고 메모리를 많이 씁니다 |
| 깊이 프리셋 | `high_accuracy`(기본): 노이즈가 적습니다(실측 3.7mm → 2.2mm). 머리카락 등에 구멍이 많으면 `default` |
| 물체 스캔 최소·최대 거리 (cm) | 이 거리 안에 있는 것만 스캔합니다(기본 15~100cm). 배경이 같이 찍히면 최대 거리를 줄이고, 큰 물체는 늘리세요. 정밀 재구성도 이 범위를 따릅니다. [근거리 (10~30cm)] / [보통 (15~100cm)] 버튼으로 바로 맞출 수 있습니다 |
| 정밀 재구성 건너뛰기 | 스캔 직후 실시간 결과만 저장합니다. 빠르지만 거칠고, 나중에 [다시 보정]할 수 있습니다 |

## 3. 물체 스캔

1. 물체를 무늬가 있는 책상이나 바닥 위에 올려 둡니다. 카메라와 30~60cm 거리가 좋습니다.
2. 실행 화면에서 **[물체 스캔]**을 누릅니다.
3. 스캔 창에서 **SPACE**를 누르고, 카메라를 들고 물체 주위를 **천천히** 돕니다.
4. 다 돌았으면 **ENTER**. 정밀 재구성(보통 수십 초~몇 분)이 끝나면 편집기가 열립니다.

| 키 | 동작 |
|---|---|
| SPACE | 스캔 시작 / 일시정지 |
| R | 처음부터 다시 |
| ENTER | 끝내고 메시 만들기 |
| ESC | 취소 |
| `]` / `[` | 최대 거리 5cm 늘리기 / 줄이기 |
| `.` / `,` | 최소 거리 5cm 늘리기 / 줄이기 |

- 왼쪽은 카메라 화면(사용 거리 밖은 어둡게), 오른쪽은 지금까지 복원된 모델입니다.
- 거리는 스캔 창 아래쪽(`range 0.15-1.00 m`)에 표시됩니다. 물체만 밝게 보이도록 SPACE를 누르기 전에 맞추면 좋습니다.

### 가까운 물체 (근거리 스캔)

D435는 두 적외선 카메라의 시차로 거리를 재는데, 찾을 수 있는 시차에 한계가 있어 **기본 설정에서는 약 15cm보다 가까운 곳을 측정하지 못합니다.**

- 최대 거리를 **40cm 이하**로 정하면 프로그램이 카메라의 시차 이동(disparity shift)을 자동으로 켜서 측정 범위를 가까운 쪽으로 옮깁니다. 실행 화면의 버튼으로 바로 맞출 수 있습니다.
- 근거리에서는 깊이 프리셋을 자동으로 `default`로 바꿉니다. `high_accuracy`는 불확실한 픽셀을 엄격하게 버려서 가까운 곳이 거의 다 사라집니다(실측: 10cm 물체에서 0.3% vs 14.5%).

| 버튼 / 최대 거리 | 측정 가능 거리 (640×480) |
|---|---|
| [보통 (15~100cm)] | 약 15cm부터 |
| 최대 40cm | 약 11~45cm |
| [가까이 (10~30cm)] | 약 10~33cm |
| [아주 가까이 (9~22cm)] | 약 9~24cm |

- 실측 (10cm 앞에 둔 물체): 기본 설정에서는 물체의 0.9%만 잡혔고, [아주 가까이]에서는 9.5cm부터 잡혀 추적 놓침 없이 스캔·정밀 재구성이 됐습니다.
- **5cm 같은 아주 가까운 거리는 D435로는 측정할 수 없습니다.** 9cm 아래로는 두 적외선 카메라가 같은 곳을 거의 보지 못합니다. 근접 촬영용 카메라(RealSense D405, 최소 약 7cm)가 필요합니다.
- 최대 거리보다 먼 곳은 측정되지 않으므로 배경이 자동으로 빠집니다. 실시간 미리보기도 2mm로 더 세밀해집니다.
- 너무 가까우면 적외선 패턴이 번져 구멍이 생길 수 있습니다. 결과에 구멍이 많으면 조금 떨어져서 찍어 보세요.
- 테두리가 **빨갛게** 되면 추적을 놓친 것입니다. 원래 자리로 돌아갈 필요 없이 그대로 천천히 움직이면 다시 붙습니다.
- 반짝이거나 검은 물체는 깊이가 잘 잡히지 않습니다.
- 결과는 저장 폴더의 `날짜_시간` 폴더에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `frames.npz` | 녹화. 나중에 다시 보정할 때 씁니다 |
| `scene_live.ply` | 스캔 중 실시간 결과 |
| `scene.ply` | 정밀 재구성 결과 |

## 4. 사람 스캔

카메라를 손에 들고 자기 자신을 찍으면 팔과 머리가 같이 움직여 여러 겹으로 번집니다. 대신 카메라를 고정하고 사람이 돕니다.

1. 카메라를 책상이나 삼각대에 **고정**하고, 회전의자에 앉아 가슴~머리가 화면 가운데 오게 맞춥니다(거리 50~80cm). 회전하지 않는 의자 다리는 화면에 안 나오게 하세요.
2. **[사람 스캔 (회전의자)]**를 누릅니다. 화면에서 **밝게 보이는 부분만** 스캔됩니다(배경 자동 제거).
3. **SPACE**를 누르면 그 순간의 거리로 대상이 고정됩니다. 발로 천천히 밀어 **30~40초에 한 바퀴** 돌고 **ENTER**.
4. 도는 동안 표정과 자세를 바꾸지 말고, 팔은 몸에 붙이거나 무릎 위에 두세요.

### 정수리(윗부분)까지 찍기

- **한 번에:** 카메라를 머리보다 조금 높게 두고 20~30° 아래를 향하게 한 뒤 한 바퀴 돕니다.
- **한 스캔 안에서 두 번 돌기 (권장):** 눈높이로 한 바퀴 → SPACE(일시정지) → 카메라를 높이 올려 아래로 향하게 → SPACE → 한 바퀴 → ENTER. 일시정지할 때마다 새 '패스'가 되어 정밀 재구성에서 자동으로 이어 붙습니다.
- **따로 찍은 두 스캔 잇기:** [7. 합치기](#7-합치기--다시-보정)를 보세요.
- 검은 머리카락은 D435의 적외선을 잘 반사하지 않아 정수리에 구멍이 생길 수 있습니다. [다듬기 도구]의 구멍 메우기로 채울 수 있습니다.

## 5. 편집기: 자르고 STL로 저장

스캔이 끝나면 자동으로 열리고, 실행 화면의 **[스캔 열기 (편집기)]**로 예전 스캔을 열 수도 있습니다.

열 수 있는 파일:
- 메시 `.ply / .obj / .stl` (편집기에서 mm로 저장한 STL도 자동으로 크기를 환산합니다)
- 녹화 `frames.npz`: 정밀 재구성을 다시 돌린 뒤 엽니다(1~3분). 기존 `scene.ply`는 `scene_prev.ply`로 보관합니다.

사용 순서:
1. 책상·바닥 평면을 자동으로 찾아 수평으로 맞추고, 그 위의 가장 큰 물체를 주황색 박스로 감싸 둡니다.
2. 슬라이더(mm)로 박스를 조절합니다. 박스 안은 원래 색, 밖은 반투명 회색입니다. `Z 최소`를 바닥 바로 위로 두면 바닥이 잘려 나가고 밑면이 평평해집니다.
   - **X / Y / Z 회전 (도):** 박스를 박스 가운데 기준으로 기울입니다(X → Y → Z 순서로 적용). 비스듬히 자르고 싶을 때 씁니다.
   - 기울여 자르면 **박스의 바닥면이 STL의 바닥(z=0)** 이 됩니다. 예를 들어 흉상을 비스듬히 자르면 잘린 면이 그대로 프린터 바닥에 붙습니다.
3. **[처리 미리보기]:** 자르기 → 가장 큰 덩어리만 남기기 → 부드럽게 → 삼각형 수 줄이기 → 구멍 메우기를 거쳐 닫힌(watertight) 메시를 만듭니다. 크기(mm)와 부피가 표시됩니다.
4. **[저장]:** STL(mm 단위, 바닥 z=0)로 저장해 슬라이서에 바로 넣으면 됩니다.

- **[이 스캔 다시 보정]:** 녹화가 있는 스캔을 최신 방식으로 다시 계산합니다.
- **[다듬기: 조각 잇기 · 구멍 메우기]:** 지금 메시를 다듬기 도구로 엽니다.

## 6. 다듬기 도구

편집기의 [다듬기] 버튼이나 실행 화면의 **[다듬기 도구]**로 엽니다.

### 1) 조각 잇기

메시를 연결된 덩어리로 나눠 목록에 보여줍니다. 가장 큰 것이 기준이고, 작은 부스러기는 자동으로 '버림'이 됩니다.

- 조각을 고르고 **이동 X/Y/Z(mm), 회전 X/Y/Z(도)** 슬라이더로 원하는 위치에 대충 놓습니다(주황 상자 = 선택한 조각).
- **[자동 맞추기]:** 겹치는 부분을 기준으로 딱 맞춥니다(실측: 15° 틀어지고 51mm 어긋난 조각을 오차 0.1mm로 복원).
- **[자동으로 위치 찾기]:** 위치를 전혀 모를 때 3D 형태로 탐색합니다. 결과가 엉뚱하면 [되돌리기].
- [이 조각 버리기] / [처음 위치로] / [되돌리기]

### 2) 구멍 메우기 (예측)

[구멍 메우기 미리보기]를 누르면 남은 조각 전체로 매끈한 표면을 예측하고, **예측한 부분은 주황색**으로 보여줍니다. 실제로 찍힌 부분은 거의 그대로 유지됩니다(차이 중앙값 0.02mm).

| 설정 | 설명 |
|---|---|
| 메울 최대 거리 | 실제 데이터에서 이만큼 떨어진 곳까지만 메웁니다 |
| 볼록함 | -1 오목 ~ 0 그대로 ~ +1 볼록. 얼굴·머리처럼 둥근 곳은 +0.3~0.5가 자연스럽습니다 |
| 매끄럽게 | 메운 부분과 경계를 부드럽게 |
| 세밀도 | 바꾸면 미리보기를 다시 눌러야 합니다 |

### 3) 끌어서 모양 다듬기

[모양 다듬기 시작]을 누른 뒤 사용합니다.

| 조작 | 동작 |
|---|---|
| Shift+클릭 | 붓 크기만큼 선택 추가(주황색) |
| Alt+클릭 | 선택 빼기 |
| Ctrl+드래그 | 선택한 부분을 끌어옵니다. 주변은 **표면을 따라 잰 거리**에 따라 부드럽게 따라옵니다(노란색) |
| 그냥 드래그 | 화면 회전 |

- **표면 방향 밀기/당기기** 슬라이더로 정밀하게 볼록/오목하게 만듭니다.
- [모양 되돌리기], [선택 해제]. [모양 다듬기 끝]을 누르면 확정됩니다.

### 4) 가우시안 스무딩

모양 다듬기 중에 잔결과 노이즈를 부드럽게 만듭니다.

- **가우시안 세기 (mm):** 1~2mm는 잔결만, 5mm 이상은 굴곡까지 완만해집니다.
- **[선택 부분 스무딩]:** Shift+클릭으로 선택한 곳만 부드럽게 합니다. 경계는 영향 반경만큼 점점 약해져서 경계선이 생기지 않습니다.
- **[전체 스무딩]:** 메시 전체를 부드럽게 합니다.
- **부피 유지:** 켜면 쪼그라들지 않습니다(실측: 반지름 50mm 구에서 세기 4mm, 켬 50.01mm / 끔 49.90mm).
- 메시로 연결된 이웃끼리만 섞으므로 귀와 머리처럼 떨어진 면이 서로 끌려가지 않습니다. 열린 가장자리는 고정됩니다.

### 5) 결과

[결과 사용]을 누르면 편집기로 돌아가 자르고 STL로 저장할 수 있습니다. [PLY로 저장]도 됩니다.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| "카메라 없음" | USB를 다시 꽂고 [카메라 다시 확인]. 다른 프로그램(RealSense Viewer 등)이 카메라를 쓰고 있으면 닫으세요 |
| "USB 2로 연결됨" | 파란색 USB 3 포트에 꽂고, 카메라에 들어 있던 USB 3 케이블(USB-C)을 쓰세요. 허브보다 PC 본체 포트가 좋습니다 |
| 추적을 자꾸 놓침 (빨간 테두리) | 더 천천히 움직이기, 무늬 있는 바닥, 30~60cm 거리 유지 |
| 결과가 여러 겹으로 번짐 | 사람 스캔은 카메라를 고정하고 의자를 돌리세요. 스캔 후 [스캔 하나 다시 보정] |
| 정수리·머리카락에 구멍 | 프리셋 `default`로 스캔하거나 다듬기 도구의 구멍 메우기 |
| 작업 창이 갑자기 꺼짐 | 실행 화면의 진행 상황에 오류 코드가 표시됩니다. [로그 폴더 열기]의 해당 작업 로그를 확인하세요 |
| 프로그램이 아예 안 켜짐 | 설치 폴더(또는 `%LOCALAPPDATA%\D435Scanner`)의 `logs\startup_error.log`를 확인하세요. 그래픽 드라이버를 최신으로 업데이트하면 해결되는 경우가 많습니다 |
| 정밀 재구성이 매우 느림 / 메모리 부족 | 해상도를 3mm로 올리거나 다른 프로그램을 닫으세요. C 드라이브 여유 공간(가상 메모리)도 확인하세요 |

- 설정 파일: `%APPDATA%\D435Scanner\config.json` (저장 폴더, 스캔 설정)
- 로그: 설치 폴더의 `logs` (쓰기 금지 폴더에 설치했다면 `%LOCALAPPDATA%\D435Scanner\logs`). 최근 30개까지 보관합니다.

## 9. 개발자용: 소스에서 실행 · 빌드

### 환경 준비

```bash
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 실행

```bash
.venv\Scripts\python.exe main.py
```

인자 없이 실행하면 실행 화면(런처)이 뜹니다. 인자를 주면 명령줄 모드로 해당 작업만 실행합니다.

| 명령 | 동작 |
|---|---|
| `main.py --preset high_accuracy` | 물체 스캔 (인자가 하나라도 있으면 명령줄 모드) |
| `main.py --subject` | 사람 스캔 |
| `main.py --load` / `--open 경로` | 편집기 |
| `main.py --repair 경로` | 다듬기 도구 |
| `main.py --merge latest2` / `--merge 폴더1 폴더2` | 스캔 합치기 |
| `main.py --recorrect [폴더...]` | 다시 보정 |
| `main.py --refine 폴더` | 다시 정밀 재구성 |

기타 옵션: `--refine-voxel 0.002`, `--no-refine`, `--voxel 0.004`, `--min-depth 0.15`, `--max-depth 1.0`, `--subject-depth 0.3`, `--seam-ref 10`. 전체 목록은 `scanner.py --help`로 확인합니다.

저장 위치는 환경 변수 `RS_SCANS_DIR`(기본 `scans`), 로그는 `RS_LOG_PATH`(기본 `logs\last_run.log`)로 바꿀 수 있습니다.

### 실행 파일·설치 파일 만들기

```bash
.venv\Scripts\python.exe -m pip install pyinstaller
winget install JRSoftware.InnoSetup
packaging\build.bat
```

- `dist\D435 Scanner\D435 Scanner.exe`: 실행 파일과 라이브러리 폴더
- `installer\D435_Scanner_Setup_1.2.0.exe`: 설치 파일
- `packaging\d435_scanner.spec`: PyInstaller 설정. 다른 패키지에 들어 있는 오래된 `MSVCP140.dll`이 섞이면 Open3D가 "DLL 초기화 루틴을 실행할 수 없습니다"로 시작하지 못하므로, 시스템의 최신 VC++ 런타임으로 바꿔 넣습니다.
- `packaging\installer.iss`: Inno Setup 설치 스크립트. 관리자 권한 없이 설치되고, 설치 중 스캔 저장 폴더를 고릅니다.

### 파일 구조

| 파일 | 내용 |
|---|---|
| `main.py` | 진입점 (인자 없음 = 런처, 인자 있음 = 명령줄 모드) |
| `launcher.py` | 통합 실행 화면. 각 작업을 같은 프로그램의 별도 프로세스로 실행 |
| `scanner.py` | 명령줄 모드: 스캔 → 정밀 재구성 → 편집기, 합치기, 다시 보정 |
| `scan.py` | 카메라 + 실시간 추적/TSDF 융합 (Open3D) |
| `refine.py` | 스캔 후 정밀 재구성 (특징점 정합, 루프, 포즈 그래프, 나쁜 프레임 제외, 패스 잇기) |
| `editor.py` | 박스 자르기 편집기 |
| `repair.py` | 다듬기 도구 (조각 잇기, 구멍 예측해서 메우기, 끌어서 모양 다듬기, 스무딩) |
| `sculpt.py` | 소프트 선택 변형, 가우시안 스무딩 |
| `mesh_tools.py` | 정렬, 자르기, 프린팅용 정리, 저장 |
| `gui_safety.py` | 화면 콜백 오류로 프로그램 전체가 꺼지지 않게 하는 안전장치 |
| `*.bat` | 소스 실행용 바로가기 (예전 방식) |

## 10. 동작 원리

### 실시간 스캔

- 컬러+깊이(Hybrid)로 프레임 간 움직임을 먼저 예측하고, 그 위치에서 렌더링한 모델에 정합해 오차를 보정합니다.
- 추적을 놓친 동안에도 연속 프레임끼리 비교해 위치를 계속 따라갑니다. 손으로 가리는 등 깊이가 잠깐 끊겼다 돌아와도 주변 후보 위치를 찾아 다시 붙습니다.
- 깊이 구멍 채우기(hole filling)는 끕니다. 없는 깊이를 지어내지 않아 경계가 깨끗합니다.
- USB 2.1 연결에서는 848×480 깊이(D435 최적 해상도)를 쓸 수 없습니다.

### 정밀 재구성 (스캔 후 자동)

1. 키프레임마다 SIFT 특징점과 깊이로 3D 특징점을 만들어 가까운 프레임(1·2·3칸)끼리 맞춥니다. 특징점이 부족한 곳(뒤통수 등)은 직전 회전 속도로 예측한 위치에서 형태(ICP)로 맞춥니다.
2. 사람 모드: 회전의자는 한 축으로만 돌므로 다른 축으로 돈 정합은 약하게 반영합니다. 정합은 머리만으로 합니다(어깨·옷은 돌면서 모양이 변해 정합을 끌고 감).
3. 한 바퀴 돌아온 프레임끼리 맞춰(루프) 누적 오차를 분산합니다. 패스끼리는 3D 형태 전체를 맞춘 뒤 프레임 쌍을 연결합니다.
4. 포즈 그래프 최적화 후 **가장 안 맞는 정합부터 조금씩 제거**합니다. 틀린 연결 하나가 전체를 휘게 하지 않도록 하기 위해서입니다.
5. 경계의 튀는 깊이를 지우고, 완성 모델과 **확실히** 안 맞는 프레임(점의 35% 이상이 벗어나고 중앙값의 3배 이상)만 빼고 다시 융합합니다.

### 마지막 연결 (한 바퀴 돌아 처음과 만나는 부분)

1. 처음 N장(기본 10장)을 순서대로 기준으로 삼아, 녹화 뒤쪽 절반의 모든 프레임과 특징점을 비교해 가장 비슷한 끝 장면을 찾습니다.
2. 여러 쌍이 같은 보정을 가리키는지 확인(합의)하고, 큰 어긋남(누적 오차)을 절반 지점부터 돈 정도에 비례해 보정합니다.
3. 처음 장면과 겹치는 뒤쪽 프레임을 **하나씩** 처음 장면에 맞춰 각자 보정합니다. 1mm 밑까지 반복합니다.

### 프레임을 최대한 살리는 원칙

- 회전축과 다른 정합, 크게 어긋난 정합은 지우지 않고 '불확실'로만 표시해 최적화가 약하게 반영하게 합니다.
- 그래프를 끊는 정합은 절대 지우지 않습니다. 정합이 끊긴 구간은 실시간 추적 자세로 약하게 이어 둡니다.
- 회전 방향을 바꿔도 놓치지 않도록 정방향·역방향·멈춤·실시간 추적 위치를 모두 시작점으로 시도합니다.
